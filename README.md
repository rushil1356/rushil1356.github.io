# Rushil Pandya — Portfolio

One-page portfolio in plain HTML, CSS and JavaScript. No build step.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Publish on GitHub Pages

1. Create a public repo named `rushil1356.github.io`.
2. Put `index.html`, `styles.css`, `script.js` and `favicon.svg` in the repo root and push.
3. The site goes live at https://rushil1356.github.io within a minute or two
   (Settings → Pages → deploy from the `main` branch if it isn't automatic).

## Editing

- Project cards and the timeline live in `index.html`.
- Case-study text for each project lives in the `caseStudies` object in `script.js`.
- Colors and fonts are tokens at the top of `styles.css`.
